# Mini Shell – 8086 Assembly Language

## Overview

Mini Shell is a command-line interface developed in 8086 Assembly Language. The project simulates a basic DOS-like shell that accepts user commands and performs various operations such as displaying help information, clearing the screen, showing date and time, performing calculations, changing colors, and echoing text.

The project was developed to strengthen understanding of Assembly Language programming, DOS interrupts, and low-level system operations.

## Features

* Command-based interface
* Help menu
* Screen clear command
* Date display
* Time display
* Calculator functionality
* Text echo command
* Color changing feature
* About section
* Exit command

## Commands Supported

| Command | Description                 |
| ------- | --------------------------- |
| help    | Display available commands  |
| cls     | Clear the screen            |
| date    | Show current date           |
| time    | Show current time           |
| calc    | Perform calculations        |
| color   | Change text color           |
| echo    | Display user text           |
| about   | Display project information |
| exit    | Terminate the shell         |

## Technologies Used

* 8086 Assembly Language

* DOS Interrupt Services

## How to Run

1. Open the project in EMU8086.
2. Load the file:

```text
mini shell.asm
```

3. Assemble and Run the program.
4. Enter commands through the shell interface.
